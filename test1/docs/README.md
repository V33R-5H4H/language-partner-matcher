## 🎯 Iteration Goals (`test1`)
This iteration focuses on the foundational client implementation and initial backend integration:
1. **Flutter Mobile Core:** Project structure, state management, and SQLite local database setup.
2. **WebRTC Client Media Service:** Camera/Mic hardware acquisition, local and remote video rendering with `flutter_webrtc`.
3. **Signaling Client Connection:** Connecting to FastAPI signaling server via WebSockets for SDP offer/answer relay.
4. **Local Persistence:** Local caching of user profile, language tables, and practice history.
